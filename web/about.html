ABOUT HUTAO HARDWARE BOOK

关于胡堂主的硬件簿

胡堂主的硬件簿是一个在浏览器内运行的设备信息检测与报告交换工具，快捷查看你的设备信息，也适合在远程协助前核对对方配置。

版本 1.6.0 报告格式 hutao-hardware-book.report v1 静态托管 · 资源本地化
打开设备检测 手机 / 平板检测 电脑端检测
TOOL

工具简介

页面打开时会完成一次设备环境检测，并按分类展示系统硬件、屏幕与 HDR、刷新率、GPU、浏览器内核、网络存储、媒体与输入能力。你可以将结果导出为 JSON 报告，在其他设备或浏览器中重新导入查看。

  • 适合在远程协助、更换硬件或排查兼容性问题前快速核对配置。
  • 远程协助摘要可用于聊天发送，完整报告可保留全部原始字段。
  • 同一份报告可在手机端与电脑端页面之间互相导入，旧版报告也可继续导入。

媒体与 API媒体设备、编解码能力、传感器接口与 Web API 支持情况
PRIVACY & PERMISSIONS

隐私与权限

设备检测、报告解析与角色渲染都在当前浏览器内完成；除你主动查询公网 IP 外，不会向服务器上传检测数据，也不加载统计或广告脚本。

  • 报告只有在你主动导出或复制后才会离开页面，分享前请检查型号、系统、屏幕与网络信息。
  • 主题和权限请求标记仅保存在 sessionStorage；公网 IP 查询会向 ipwho.is 发送当前网络请求，结果不写入报告。

COMPATIBILITY

浏览器与平台

页面会依据操作系统、浏览器标识与触控特征自动选择检测视图。Android、iOS、iPadOS、HarmonyOS 手机与平板进入移动端页面；Windows、macOS、Linux、ChromeOS 设备进入电脑端页面。

  • 建议使用较新版本的 Chrome、Edge、Safari、Firefox 或其他现代浏览器。
  • 页面默认跟随系统主题，并允许使用右上角按钮在亮色与暗色之间切换。
  • Live2D 角色需要 WebGL；若浏览器不支持，页面会跳过角色展示，不影响设备检测。
